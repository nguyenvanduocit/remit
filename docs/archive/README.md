# Archive

The evidence and the review record behind Remit's design. It is kept for reading and is not maintained: `docs/design.md` is the
system as it is, `docs/remit-design.md` is the direction, and `docs/adr` holds the decisions.

| Path | What |
|---|---|
| `ai-run-company-blueprint.md` | the operating method and its evidence: invariants I1-I19, day-0 checks D1-D18, the known holes of the reference implementation |
| `research-ai-autonomous-system-{evidence,design,pilot,risk}.md`, `brainstorm-ai-autonomous-system.md` | the research and the brainstorm the blueprint is built from |
| `council/` | the four council drafts, six challenges and four reviews of the design |
| `reviews/2026-10-27-architecture-review.md` | an eight-lens architecture review of that date |
| `papers/` | the cited papers (`INDEX.md`) |
